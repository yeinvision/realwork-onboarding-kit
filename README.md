## 🎯 프로젝트 개요

리얼워크는 조직개발 컨설팅 회사로, 새로운 팀원들이 **빠르고 효율적으로** 회사 문화와 업무를 이해할 수 있도록 돕기 위해 이 온보딩 키트를 개발했습니다.

### 핵심 가치
- ✅ **자율 학습**: 신입이 선임 시간에 맞춰 스스로 학습
- ✅ **체계적 진행**: 3단계 커리큘럼으로 명확한 학습 경로
- ✅ **실전 준비**: 사례 분석으로 실무 감각 기르기
- ✅ **지속 가능**: 새로운 팀원 추가 시 쉽게 확장

---

## 📚 온보딩 구조

### 3단계 학습 체계

```
Stage 1: 기본 이해 (1시간)
  ├─ 리얼워크 소개
  ├─ 조직 구조
  ├─ 회사 문화
  └─ 주요 용어

Stage 2: 사례 & 문화 (1시간)
  ├─ 실제 프로젝트 사례
  ├─ 핵심 역할 (PM/PL/FT)
  ├─ 비즈니스 모델
  └─ 회사 철학

Stage 3: 워크숍 SOP (2시간)
  ├─ 전/중/후 단계
  ├─ 각 역할의 책임
  ├─ 줄리의 실전 팁
  ├─ 역할 시뮬레이션
  └─ 학습 체크리스트
```

### 추가 학습 자료

| 자료 | 설명 | 대상 |
|------|------|------|
| **FAQ 30개** | 예상되는 질문과 답변 | 신입 |
| **팀원 소개** | 각 팀원 역할 정보 | 신입 |
| **용어 사전** | 업무 용어 40+ (확장 가능) | 신입 |
| **사례 분석** | 실전 연습 (3가지 사례) | 신입 |
| **선임 준비** | 온보딩 체크리스트 | 선임 |

## 📝 주요 콘텐츠 미리보기

### 줄리의 핵심 노하우 3가지
1. **협상하듯이 조금씩 제공** - 한 번에 다 주지 말기
2. **현장에서 담당자와 깊게 소통** - Co-FT 역할
3. **FT 피드백을 통한 성장** - 나도 배우고 FT도 성장

### 리얼워크의 철학
> "단순 교육으로 끝나지 않는다"
> 
> 워크숍 후에도 고객의 변화가 실제로 일어났는지 
> 끊임없이 체크하는 End & And

## ✨ 이 온보딩의 특별한 점

```
기존 온보딩 vs 리얼워크 온보딩

기존:
선임 강의 → 신입 수동 학습 → 휴류
(시간이 오래 걸리고, 품질 일관성 없음)

리얼워크:
신입 자율 학습 + 선임 지원 → 체계적 성장
(효율적이고, 품질 일관성 있음)
```

## 🎯 성공 지표

온보딩 완료 후 신입이 다음을 만족하면 성공입니다:

- ✅ 리얼워크의 조직과 문화를 이해한다
- ✅ 워크숍의 전/중/후 프로세스를 알 수 있다
- ✅ 자신의 셀 역할을 이해한다
- ✅ 팀원들과 편한 관계를 맺었다
- ✅ 최소 1개 프로젝트에 참여해본 경험이 있다
- ✅ 어려움이 있을 때 선임에게 물을 자신감이 있다
