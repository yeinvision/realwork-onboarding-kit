# RealWork 생존 온보딩 키트

> **신입이 자기주도적으로 배우고, 이해하고, 적응할 수 있도록 돕는 생존 온보딩 키트입니다.**

![RealWork Logo](https://img.shields.io/badge/RealWork-Onboarding_Kit-00ACC1?style=flat-square)

## 📌 개요

리얼워크는 현재 **15명의 팀원**으로 구성된 혁신적인 기업입니다. 모든 팀원이 바빠서 신입에게 오랜 시간을 투자할 수 없기 때문에, **자기주도적 학습**을 지원하는 온보딩 키트를 만들었습니다.

### 🎯 이 키트의 목표
- ✅ **스스로 배울 수 있는** 온보딩 경험 제공
- ✅ **리얼워크의 업무 환경** 빠르게 이해
- ✅ **회사 문화와 가치** 체험
- ✅ **실무 프로세스** 습득

---

## 📚 학습 구성

### 🎓 **3단계 커리큘럼** (총 4-5시간)

#### **1단계: 리얼워크 멤버로 시작하기** (1시간)
- 업무 환경 세팅 (노션, 슬랙, 메일 등)
- 팀 멤버 소개 및 인사
- 기본 용어 및 업무 흐름 이해
- 사무실 이용 규칙

#### **2단계: 리얼워크 알아가기** (1시간)
- 회사의 다양한 사례 학습
- 리얼워크만의 독특한 문화 체험
- 각 셀(팀)의 역할과 특징 이해
- 고객 커뮤니케이션 방식

#### **3단계: 실무 프로세스 습득** (2시간)
- 워크숍 SOP (표준운영절차) 학습
- 프로젝트 유형별 프로세스 이해
- 각 역할(PM, PL 등)의 책임 파악
- 실제 사례로 배우는 문제 해결

## 🚀 시작하기

### 👉 **신입 가이드**
이 사이드바의 메뉴를 위에서부터 차례대로 따라가세요!
- **📖 README** - 지금 보고 있는 이것입니다
- **🎯 시작하기** - 첫 번째 체크리스트
- **3️⃣ 3단계** - 실무 프로세스 학습
- **❓ FAQ** - 자주 묻는 질문 30가지
- **👥 팀 소개** - 리얼워크 팀원들 소개
- **📚 용어사전** - 업무 용어 정리
- **📊 프로젝트** - 실제 사례로 배우기
- **🎓 사수준비** - 선임을 위한 가이드

### 🎯 **사수를 위한 가이드**
신입을 맡기기 전에:
1. **사수준비** 탭에서 준비 사항 확인
2. 신입의 이름, 포지션 등 입력
3. 신입에게 이 링크 공유
4. 신입이 자기주도적으로 학습하도록 격려

## 💡 이 키트의 특징

### ✨ **자기주도 학습**
시간이 없는 바쁜 팀원들을 위해 신입이 **혼자서도 학습**할 수 있도록 구성했습니다.

### 🎨 **실용적 콘텐츠**
이론이 아닌 **실제 업무에 필요한** 정보만 담았습니다.

### 🔄 **단계별 진행**
각 단계마다 이해도를 확인하고 다음 단계로 진행합니다.

### 🎓 **게임화 요소**
퀴즈, 오엑스 게임 등으로 학습을 재미있게 만들었습니다.
